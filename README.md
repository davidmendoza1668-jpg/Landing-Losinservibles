# BrillaMax 🚗✨

## Descripción

BrillaMax es una página web creada para un negocio ficticio de **lavado de vehículos**.

La página permite mostrar los servicios ofrecidos y proporciona información para que los clientes puedan comunicarse con el negocio.

## Secciones de la página

La página HTML contiene 3 secciones principales:

1. 🏠 **Inicio**
2. 🚗 **Servicios**
3. 📞 **Contacto**

## Servicios

Los servicios que ofrece BrillaMax son:

- Lavado Básico
- Lavado Completo
- Limpieza Interior

## Contacto

La sección de contacto contiene:

- 📍 Dirección.
- 📞 Teléfono.
- ✉️ Correo electrónico.
- 🕒 Horario de atención
- Redes sociales.
- Formulario de contacto

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
